✅ Manejadores de Error Implementados:

  • 400: Solicitud Incorrecta — Datos inválidos del cliente
  • 403: Acceso Prohibido — Permiso denegado
  • 404: No Encontrado — Página/recurso no existe
  • 500: Error Interno — Error del servidor
  • 502: Bad Gateway — Problema de comunicación
  • 503: Servicio No Disponible — En mantenimiento
